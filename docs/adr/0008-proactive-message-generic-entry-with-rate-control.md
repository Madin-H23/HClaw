# 系统级主动消息走通用入口+独立频控层，不经任务定义

IM 自动化批（批二）新增通用主动消息入口：任意触发源（MVP=上游定时调度器）→ 频控层 → 指定渠道 → admin 私聊会话。频控是独立策略层（渠道全局限速/任务级静默窗口/同会话同类型冷却去重，配置驱动），不寄生在任务语义里——上游现成的「任务结果投递」与「Proactive 会话模式」都只绑死单一触发语义，个人自动化动线（晨检/探活类到点播报）需要的是脱离任务定义的发声能力。

**Considered Options**: ①沿用任务结果投递——触发源被任务定义锁死，加新触发就得造伪任务，语义倒挂，弃；②Proactive 会话模式——需要工作区进入专用交互模式且消息只能出自 Agent，系统侧播报（如「探活正常，今日静默」）无 Agent 回合也想发，弃。

**Consequences**: 频控失败语义沿 ADR-0004 fail-open——频控组件不可用时消息直发（宁多勿丢，个人自托管场景）；推送目标 MVP 仅 admin 私聊，群播是后续扩展位。
